# basic Calculator

A simple Python calculator that performs basic arithmetic operations while handling invalid user input.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation
- Prevents the program from crashing when invalid input is entered
- Allows the user to continue using the calculator

## Technologies Used

- Python

## How to Run

1. Download or clone this repository.
2. Make sure Python is installed.
3. Open the project in VS Code or a terminal.
4. Run:

```bash
python basic_calculator.py
